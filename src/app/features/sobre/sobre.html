SOBRE O PROJETO

MakerLab

Um sistema simples para organizar o controle de impressões 3D.

Objetivo

O MakerLab permite registrar projetos de impressão 3D e acompanhar informações importantes, como material utilizado, peso estimado, duração, solicitante, data do pedido e situação da impressão.

Funcionalidades

  • Cadastro de novos projetos de impressão.
  • Consulta e visualização dos projetos cadastrados.
  • Edição e exclusão de registros.
  • Armazenamento dos dados no Firebase Realtime Database.
